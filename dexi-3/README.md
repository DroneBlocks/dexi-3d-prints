# DEXI 3

## MicoAir flow sensor case

`DEXI 3 MicoAir Flow Case Top.step` and `DEXI 3 MicoAir Flow Case Bottom.step` hold the MicoAir flow sensor.

`DEXI 3 MicoAir Flow Mount 90 Degrees Rotated.step` is the same mount rotated 90 degrees, a safer option for cable routing.

**Note:** to mount this flow sensor, replace the 20 mm standoffs with 15 mm standoffs.
